# 琳宝私厨 - 情侣双人私厨点菜小程序

## 项目简介
这是一个专门为情侣设计的双人私厨点菜小程序，实现"厨神上架菜品 → 吃货点菜下单 → 接单制作 → 完成打卡"的完整闭环。

## 技术栈
- 微信小程序原生开发
- 微信云开发（云数据库 + 云函数 + 云存储）
- 粉紫可爱风UI设计

---

## 🚀 快速开始

### 第一步：导入项目
1. 打开微信开发者工具
2. 选择"导入项目"
3. 选择 `linbao-sichu` 文件夹
4. 填入你的小程序 AppID

### 第二步：开通云开发
1. 点击工具栏上的"云开发"按钮
2. 开通云开发环境，选择基础版
3. 复制你的云环境ID

### 第三步：修改配置
1. 打开 `miniprogram/app.js`
2. 找到 `env: 'your-env-id'`，替换成你的云环境ID
3. 打开 `project.config.json`
4. 把 `appid` 改成你的小程序 AppID

### 第四步：创建数据库集合
在云开发控制台的数据库页面，创建以下集合：
- `users` - 用户表
- `couples` - 情侣配对表
- `dishes` - 菜品表
- `categories` - 菜品分类表
- `orders` - 订单表
- `posts` - 社区动态表
- `fridge_items` - 食材冰箱表

### 第五步：上传云函数
右键点击 `cloudfunctions` 文件夹下的每个云函数，选择"上传并部署：云端安装依赖"

```
│   │   ├── home/            # 首页（家）

│   │   ├── discover/       # 发现页

│   │   └── order-detail/    # 订单详情

│   ├── utils/               # 工具函数

│   ├── app.json             # 全局配置
│   └── app.wxss             # 全局样式

│   ├── login/               # 登录
│   └── createOrder/         # 创建订单

```
