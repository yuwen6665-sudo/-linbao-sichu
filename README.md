## 一、第一次跑起来（或换电脑）

### 1. 导入项目

微信开发者工具 → 导入项目 → 选这个文件夹。
AppID 和云环境 ID **都已经写死在代码里**，克隆下来直接能跑，不用替换：

| 项 | 值 |
|---|---|
| AppID | `wxb8602c450dc0330d`（个人主体，类目「工具 → 备忘录」） |
| 云环境 ID | `cloud1-d9gq6m7n5e57e97c6`（在 `miniprogram/utils/api.js` 的 `CLOUD_ENV`） |

### 2. 建 6 个数据库集合

云开发控制台 → 数据库 → 新建集合，一共 6 个：

`users` · `couples` · `dishes` · `orders` · `posts` · `moods`

⚠️ 权限一律设成 **「所有用户不可读写」**。前端不直接碰数据库，所有读写都走云函数
（云函数是管理员身份，不受这个限制）。

### 3. 部署 11 个云函数

对每个文件夹**右键 →「上传并部署：云端安装依赖（不上传 node_modules）」**：

| 云函数 | 干什么 | 不部署会怎样 |
|---|---|---|
| `login` | 登录、自动建号 | 打不开 |
| `data` | **所有读操作**（菜单、订单、日志、心情） | 页面空白、**「共 0 道菜」** |
| `createOrder` | 下单 | 点不了菜 |
| `updateOrder` | 接单 / 做完 / 拒单 / 取消 / 打分 | 订单卡住 |
| `bindPartner` | 生成邀请码、绑定、解绑 | 绑不了 |
| `updateProfile` | 改资料、切身份 | 切不了角色 |
| `post` | 写日志、点赞、设心情 | 发现页写不了 |
| `sendNotify` | 发订阅消息 | 收不到提醒 |
| `getFileURL` | 头像换链接 | 头像不显示 |
| `initDishes` | **一键灌 200 道菜** | 菜库是空的 |
| `cacheDishImages` | 把外链图转存进云存储 | **真机上菜品图一片空白** |

> 部署完去控制台**确认一下超时时间**（函数 → 配置 → 超时时间），跑得久的那几个要 **60 秒**。
> 云函数默认只给 3 秒，不够用。

### 4. 灌菜库（一次就好）

控制台 → 云函数 → `initDishes` → 云端测试 → 参数填 `{}` → 运行

预期返回 `inserted: 200`（第一次）或 `updated: 200`（已有数据时）。
幂等，超时了再点一次「运行」接着补，不会写重复。

### 5. 转菜品图（**必须做**）

菜品图原本是豆果网的 `http://` 外链，**真机强制 HTTPS 会直接拦掉**，不转就是一片空白。

控制台 → `cacheDishImages`：
1. 参数 `{"probe": true}` → 只看数、不动数据
2. 参数 `{}` → 开始转，看返回的 `remaining`，**不是 0 就再点一次**，直到 0

### 6. 编译，然后**用真机看**

右上角「预览」扫码。**开发者工具模拟器的点击层会坏**（页面渲染正常、点哪都没反应），
这坑踩过好几轮 —— 凡是要验"点"的功能，一律上真机。

## 三、改菜谱数据

**别手改 `cloudfunctions/initDishes/dishes.js`** —— 那是脚本生成的，改了下次一跑就没了。

正确流程：

1. 改根目录的 `琳宝私厨200道菜导入.json`（一行一条 JSON）
2. 跑转换脚本：
   ```
   node C:/Users/yuwen/WorkBuddy/2026-09-18-16-54-08/tools/convert_dishes.js --no-merge
   ```
   （`--no-merge` = 只要那 200 道，不要老的手写菜）
3. **重新部署 `initDishes`** → 再跑一次参数 `{}`

要改某道菜的名字：加一行到脚本里的 `NAME_FIX` 映射表
（比如「微体兔菜谱这酸爽难以抗拒！酸菜鱼」→「酸菜鱼」）。**别用正则批量改** ——
「西班牙海鲜饭Paella」里的外文是菜名的一部分，正则必然误伤。

## 四、几个必踩的坑（都是真踩出来的）

1. **云函数的返回值在 `res.result`，不是 `res.data`**
   写错的表现极误导：云函数跑成功了，前端却一律判失败。

2. **模拟器不可靠** —— 要验"点"就上真机。

3. **图片**：http 明文真机不显示；云存储的图片要经云函数换成临时链接
   （免费套餐改不了存储权限，`data` 里的 `CONVERT_TO_TEMP_URL` 就是控制这个的开关）。

4. **云函数默认 3 秒超时** —— `config.json` 里写了 60 也**不一定生效**，
   部署后去控制台看一眼才靠谱。

5. **前端不能直接读数据库** —— 权限设的是不可读写，直接读必失败，而且**不报错**，
   页面只是空的，很难查。

6. **绑定用邀请码，不是分享卡片** —— 未认证的小程序分享给好友会被微信限制，
   这不是 bug，是平台规则，修不了。

7. **订单动作要校验"该不该由他做"** —— 只查"是不是这一家人"不够，
   点菜的人能自己把自己的单接掉。已按订单的 `toOpenid` 加上了。

## 五、明确不做的事

- ❌ 不做陌生人社交 / 广场 / 附近的人 / 偷菜
